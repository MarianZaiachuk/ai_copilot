# AI Copilot для Zoom

Легка десктопна утиліта для Windows (`.exe`), яка перехоплює системний звук через **WASAPI Loopback** (без віртуальних аудіокабелів і ботів у конференції), локально розпізнає українську мову на GPU через **faster-whisper**, формує короткі тезисні або розгорнуті відповіді з опорою на ваші документи та показує підказки в напівпрозорому **Stealth-оверлеї** (`WDA_EXCLUDEFROMCAPTURE`), невидимому під час демонстрації екрана в Zoom / Discord / OBS.

## Ключові можливості та вдосконалення

- **Покращена українська транскрибація (GPU + CPU фолбек):** `faster-whisper` (`large-v3-turbo` або `large-v3` із повним 32-шаровим декодером для максимальної точності, `float16` на CUDA), примусова мова `language="uk"`, **soft-cut нарізка по мікропаузах між словами** (`5.0 с` чанки + `0.85 с` перекриття), авто-підсилення тихої мови, український `initial_prompt`, нативні `hotwords`, налаштований **Silero VAD** (`threshold=0.35`, `speech_pad_ms=380`), нечітка дедуплікація стиків та нормалізація ІТ-термінів (включно з кириличними транскрипціями на кшталт «васапі» → `WASAPI`).
- **Стійке захоплення звуку:** неблокуючий WASAPI Loopback з автоматичним перепідключенням (до 3 спроб) при зміні або відключенні гарнітури.
- **Гібридний контекст (CAG + Hybrid RAG):** невеликі документи передаються повністю у фіксованому порядку (оптимізовано під prefix caching), а великі корпуси автоматично розбиваються за структурою сторінок/заголовків/функцій та ранжуються через український BM25 + 4-gram пошук.
- **Безпека та приватність:** маскування API-ключів (`AIza...`, `sk-...`, `gsk_...`, `Bearer ...`) у ротованому `copilot.log` та повідомленнях про помилки, атомарний запис `.env`, захист від prompt-injection через XML-розмежування даних.
- **Перевірка API-ключа та актуальні моделі 2026:** підтримка `OpenAI` (`gpt-6-luna`, `gpt-6.1-sol`), `Groq` (`qwen/qwen3.8-27b`, `openai/gpt-oss-20b`, `groq/compound-mini`, `groq/compound`), `Google Gemini` (`gemini-3.8-flash`, `gemini-3.5-flash-lite`, `gemini-4-*`), локальних `Ollama` і `LM Studio`; перевірка валідності ключа й моделі кнопкою **«✓ Перевірити ключ»** та завантаження живого списку доступних моделей кнопкою **«↻ Завантажити моделі»**.
- **Швидкий веб-пошук із пріоритетом документів (`🌐 Веб`):** коли веб-пошук увімкнено і завантажено файли контексту, копайлот **спочатку аналізує ваші документи** і відповідає одразу без мережевих запитів; пошук в інтернеті запускається лише тоді, коли відповіді в документах немає. Підтримує швидкий потоковий AI-агент на **Groq** (`reasoning_effort=none`, паралельний виклик інструментів, 180 с TTL-кеш, `DDGS` / Вікіпедія / Tavily / Brave), **`groq/compound-mini`**, **Google Search Grounding** у Gemini та опційний **`obscura.exe`**.
- **Зір екрана (`👁 Екран`) для аналізу коду:** при увімкненій кнопці **`👁 Екран`** агент при кожному запиті робить миттєвий JPEG-знімок вибраного монітора ([screen_capture.py](file:///c:/Users/OPIUM/Downloads/ai_copilot/screen_capture.py), сам Stealth-оверлей при цьому невидимий на скріншоті). На **Groq** зображення обробляється мультимодальною моделлю `qwen/qwen3.8-27b` (якщо вибрана суто текстова модель Groq на кшталт `llama-3.1-8b-instant`, програма автоматично перемикається на `qwen/qwen3.8-27b` для аналізу кадру); також підтримуються **Gemini**, **OpenAI** та мультимодальні локальні моделі **Ollama**.
- **Інтуїтивний інтерфейс і ручне введення прямо в оверлеї:** панель керування ([dashboard.py](file:///c:/Users/OPIUM/Downloads/ai_copilot/dashboard.py)) зі згортанням у системний трей, захистом від запуску дублікатів (`QLocalServer`), індикатором завантаження Whisper, експортом сесії в `.md`, а також компактний Stealth-оверлей ([ui.py](file:///c:/Users/OPIUM/Downloads/ai_copilot/ui.py)) із постійно доступним полем для введення запитань (`Enter` / «Надіслати»), кнопками копіювання (`📋`), розгортання (`⤢` / `▭`) та **«Детальніше →»**.

## Швидкий запуск через `.exe`

1. Відкрийте ярлик **`ZoomAICopilot.lnk`** або запустіть напряму:
   `dist\ZoomAICopilot\ZoomAICopilot.exe`
2. У **«Налаштування → LLM Провайдер»** оберіть провайдера, вставте ключ (якщо хмарний API), натисніть **«✓ Перевірити ключ»** або **«↻ Завантажити моделі»**, потім **«Зберегти та застосувати»**.
3. У розділі **«Документи»** перетягніть файли звіту/коду/конспекту (`.pdf`, `.docx`, `.txt`, `.md`, `.py`, `.cpp` тощо) та за потреби додайте спеціальні терміни у поле **«Словник термінів»**.
4. На **«Головній»** оберіть аудіопристрій з позначкою `★` і натисніть **«▶ Почати сесію»**.

## Гарячі клавіші (незалежно від розкладки UA/EN)

- **`Ctrl + Space`** — коротка тезисна відповідь (3–5 буліт-поїнтів) за останні 60 секунд або виділений фрагмент.
- **`Ctrl + Shift + H`** — показати або сховати оверлей.

## Розробка, тести, лінтинг та збірка `.exe`

```powershell
# Створення .venv та встановлення залежностей
python -m venv .venv
.venv\Scripts\pip.exe install -r requirements.txt
.venv\Scripts\pip.exe install -r requirements-dev.txt
.venv\Scripts\pip.exe install -r requirements-build.txt

# Запуск лінтера та автотестів
.venv\Scripts\ruff.exe check .
.venv\Scripts\pytest.exe -v

# Збірка портативного .exe (автоматично зберігає наявний dist\ZoomAICopilot\.env)
.venv\Scripts\python.exe build_exe.py
```

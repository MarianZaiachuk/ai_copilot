# AI Copilot для Zoom

Десктопний асистент для Windows у реальному часі: перехоплює системний звук через **WASAPI Loopback** (без віртуальних аудіокабелів і ботів у конференції), розпізнає мову через **хмарні STT-сервіси** (ElevenLabs Scribe v3, Deepgram Nova-3, Groq Whisper) або локальний **faster-whisper** (CUDA/CPU), аналізує контекст ваших документів та екран і показує підказки в захищеному **Stealth-оверлеї** (`WDA_EXCLUDEFROMCAPTURE`), невидимому під час демонстрації екрана в Zoom / Discord / OBS.

## Встановлення (Windows Releases)

Оберіть потрібний інсталятор у розділі [GitHub Releases](https://github.com/MarianZaiachuk/ai_copilot/releases):

- **`ZoomAICopilot-Lite-Setup-v1.3.exe`** (~157 МБ) — легка версія для швидкого старту та ПК без NVIDIA GPU. Працює через хмарний STT (ElevenLabs / Deepgram / Groq) без локального PyTorch/CUDA.
- **`ZoomAICopilot-Setup-v1.3.exe`** (~1.32 ГБ) — повна версія з локальним **faster-whisper** (GPU CUDA + CPU фолбек) і підтримкою хмарних STT-провайдерів.

> **Примітка про збереження налаштувань:** під час встановлення у `Program Files` конфігураційний файл `.env`, предметні профілі, індекси документів і журнал `copilot.log` автоматично зберігаються в `%APPDATA%\ZoomAICopilot`. У портативному режимі (`dist\ZoomAICopilot`) ці файли зберігаються поруч із `.exe`. Усі змінні середовища задокументовані в [.env.example](.env.example).

## Ключові можливості

- **Хмарний STT + локальний Whisper:**
  - Хмарні рушії: **ElevenLabs Scribe v3**, **Deepgram Nova-3**, **Groq Whisper** для миттєвого розпізнавання без навантаження на локальну відеокарту.
  - Локальний **faster-whisper**: `large-v3-turbo` або `large-v3` (`float16` на CUDA із фолбеком на CPU), **Silero VAD** (`threshold=0.35`, `speech_pad_ms=380`), **soft-cut нарізка по мікропаузах** (`5.0 с` чанки + `0.85 с` перекриття), авто-підсилення тихої мови, нечітка дедуплікація стиків та нормалізація термінів.
  - Підтримка мов: `uk`, `en`, `en+uk` (змішана українсько-англійська мова) та `auto`.
  - Стійке захоплення системного звуку через неблокуючий WASAPI Loopback з автоматичним перепідключенням (до 3 спроб) при зміні гарнітури.
- **Актуальні LLM-провайдери та ізоляція ключів:**
  - Підтримка **OpenAI** (`gpt-6-luna`, `gpt-6.1-sol`), **Groq** (`qwen/qwen3.8-27b`, `openai/gpt-oss-20b`, `groq/compound-mini`, `groq/compound`), **Cerebras** (`qwen-3.8-27b`, `gpt-oss-120b`), **Google Gemini** (`gemini-3.8-flash`, `gemini-3.5-flash-lite`), а також локальних **Ollama** і **LM Studio**.
  - Окремі API-ключі й активні моделі для кожного провайдера (без перехресного перезапису), **авто-фолбек** на інший налаштований провайдер (`LLM_FALLBACK_PROVIDER=auto`) при 429/таймауті/5xx, перевірка валідності кнопкою **«✓ Перевірити ключ»** та завантаження доступного списку кнопкою **«↻ Завантажити моделі»**.
- **Зір екрана (`👁 Екран`) та виділення області Snip-to-Ask (`✂` / `Ctrl + Alt + A`):**
  - При увімкненні **`👁 Екран`** копайлот робить миттєвий JPEG-знімок вибраного монітора ([screen_capture.py](screen_capture.py)), причому Stealth-вікна самого копайлоту залишаються невидимими на кадрі.
  - Кнопка **`✂`** (або **`Ctrl + Alt + A`**) відкриває Stealth-рамку для точного виділення графіка, формули чи фрагмента коду з миттєвим аналізом.
  - Підходить не лише для коду, а й для **графіків, схем, формул і дошки Zoom**: модель відповідає на останнє питання викладача по теорії чи зображенню без зайвого переказу коду проєкту, якщо про код не питали.
  - Якщо обрано суто текстову модель на **Cerebras** або **Groq**, для запитів із Зіром екрана виконується автоматична маршрутизація на мультимодальну модель (`qwen-3.8-27b` на Cerebras / `qwen/qwen3.8-27b` на Groq); також підтримуються **Gemini**, **OpenAI** та мультимодальні локальні моделі **Ollama**.
- **Швидкий веб-пошук із пріоритетом документів (`🌐 Веб`):**
  - Коли веб-пошук увімкнено і завантажено документи, копайлот **спочатку перевіряє ваші файли** та відповідає без зайвих мережевих запитів; інтернет-пошук запускається лише тоді, коли в документах немає відповіді.
  - Підтримує швидкого потокового AI-агента (`DDGS`, Вікіпедія, Tavily, Brave), `groq/compound-mini`, **Google Search Grounding** у Gemini та опційний `obscura.exe`.
- **Предметні профілі, експорт/імпорт та гібридний контекст (CAG + Hybrid RAG):**
  - Створення, перейменування, видалення, **експорт/імпорт у `.json`** (без API-ключів і локальних шляхів) та перемикання предметних профілів у вкладці **«Документи»** і через **системний трей** — кожен профіль зберігає власний системний промпт, мову STT, словник термінів і набір документів.
  - Невеликі документи передаються повністю (оптимізовано під prefix caching), а великі корпуси автоматично індексуються й ранжуються через український **BM25 + 4-gram RAG**.
- **Посилений Stealth-режим (`WDA_EXCLUDEFROMCAPTURE`):**
  - Захист від захоплення екрана завжди активний при запуску як для оверлея, так і для панелі керування.
  - Вбудований DWM-наглядач перевіряє стан вікон кожні 2 с та автоматично відновлює захист; вимкнути Stealth можна лише в **«Налаштування»** через діалог підтвердження.
- **Зручний інтерфейс, LaTeX-формула і надійний старт:**
  - Панель керування ([dashboard.py](dashboard.py)) зі згортанням у системний трей, захистом від дублікатів запуску (`QLocalServer`), асинхронним оновленням аудіопристроїв та експортом сесії в `.md`.
  - Компактний Stealth-оверлей ([ui.py](ui.py)) із **рендером LaTeX-формул** ([latex_renderer.py](latex_renderer.py)), клікабельною історією карток (`‹ n/m ▾ ›`), постійним полем ручного введення запитань (`Enter` не перемикає кнопки `👁 Екр.` / `🌐 Веб`), кнопками **`✂`**, **`📋`**, **`⤢` / `▭`** і **«Детальніше →»**.
  - Універсальний запуск на будь-якому ПК: захищений старт із діалогом помилки, миттєвий Splash-екран, авто-фолбек Qt Software rendering (`--software`), автономна діагностика ([diagnostics.py](diagnostics.py), `--diagnose`), автоперевірка `VC++ Redistributable x64` в інсталяторі, маскування ключів у `copilot.log`, атомарний запис `.env`, XML-розмежування даних проти prompt-injection.

## Швидкий старт

1. Завантажте й запустіть інсталятор (`ZoomAICopilot-Lite-Setup-v1.3.exe` або `ZoomAICopilot-Setup-v1.3.exe`) та відкрийте **AI Copilot** із меню «Пуск» або ярлика на робочому столі.
2. У **«Налаштування → LLM Провайдер»** оберіть провайдера, вставте API-ключ, натисніть **«✓ Перевірити ключ»** або **«↻ Завантажити моделі»** і збережіть зміни.
3. У **«Налаштування → Розпізнавання мови (STT)»** оберіть хмарний STT (наприклад, ElevenLabs / Deepgram / Groq) або локальний `faster-whisper` (у повній версії).
4. У розділі **«Документи»** оберіть або створіть предметний профіль, перетягніть файли конспекту/звіту/коду (`.pdf`, `.docx`, `.txt`, `.md`, `.py`, `.cs`, `.cpp` тощо) та за потреби додайте спеціальні терміни у **«Словник термінів»**.
5. На **«Головній»** оберіть аудіопристрій із позначкою `★` і натисніть **«▶ Почати сесію»** (або `Ctrl + Alt + R`).

## Гарячі клавіші (незалежно від розкладки UA/EN)

- **`Ctrl + Space`** — коротка тезисна відповідь (3–5 буліт-поїнтів) за останні 60 секунд або виділений фрагмент.
- **`Ctrl + Shift + H`** — показати або сховати оверлей.
- **`Ctrl + Alt + R`** — почати або зупинити сесію прослуховування.
- **`Ctrl + Alt + S`** — увімкнути або вимкнути Зір екрана (`👁 Екран`).
- **`Ctrl + Alt + W`** — увімкнути або вимкнути Веб-пошук (`🌐 Веб`).
- **`Ctrl + Alt + A`** — виділити область екрана (`✂` Snip-to-Ask: графік, формула, код).

## Розробка, тести та збірка

```powershell
# Створення .venv та встановлення залежностей
python -m venv .venv
.venv\Scripts\pip.exe install -r requirements.txt
.venv\Scripts\pip.exe install -r requirements-dev.txt
.venv\Scripts\pip.exe install -r requirements-build.txt

# Запуск лінтера та автотестів
.venv\Scripts\ruff.exe check .
.venv\Scripts\pytest.exe -v

# Збірка Full-версії (dist\ZoomAICopilot\ZoomAICopilot.exe, зберігає наявний .env)
.venv\Scripts\python.exe build_exe.py

# Збірка Lite-версії (dist_lite\ZoomAICopilot\ZoomAICopilot.exe, без PyTorch/CUDA)
$env:ZOOM_COPILOT_LITE='1'
.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean --distpath dist_lite --workpath build_lite ZoomAICopilot.spec
Remove-Item Env:ZOOM_COPILOT_LITE
```

Компіляція інсталяторів Windows через Inno Setup ([installer/ZoomAICopilot.iss](installer/ZoomAICopilot.iss)):

```powershell
# Full інсталятор -> release\ZoomAICopilot-Setup-v1.3.exe
ISCC.exe installer\ZoomAICopilot.iss

# Lite інсталятор -> release\ZoomAICopilot-Lite-Setup-v1.3.exe
ISCC.exe /DBuildVariant=Lite /DSourceDir=..\dist_lite\ZoomAICopilot installer\ZoomAICopilot.iss
```
